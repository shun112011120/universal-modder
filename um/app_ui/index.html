What do you want to mod?

The AI runs on your own Ollama and works with the toolkit: it finds your games, checks how they can be modded, backs up your saves, writes mod files into your workspace, and asks before anything risky.

Games

Click Find my games to list your Steam, Epic and Xbox games.
Pick a game to see its engine, anti-cheat, mod loaders, save folders and the best way to mod it.

Backups

Back up a folder

Snapshot a save folder before you mod. The Games screen shows each game's save folders.

Publish check

Run this before sharing a mod. It fails on copied game files and leaked keys, and warns about decompiled code, missing README or credits, and personal paths.

Settings

AI model (Ollama)

Install Ollama from ollama.com, then pull a model that supports tools, for example ollama pull qwen3-coder (needs a strong GPU) or ollama pull qwen3:8b (smaller).

Bigger context lets the AI keep more of the guides and files in mind, but uses more GPU memory.

Workspace

Where the AI writes new mod files without asking. Writing anywhere else needs your OK.
